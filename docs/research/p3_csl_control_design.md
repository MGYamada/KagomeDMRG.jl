確認日: 2026-09-19。状態: **一次資料に基づく設計。CSL ポンプは未検証**。
最近接模型の `M/Msat=1/9` とは別の、零磁化・拡張交換模型を正応答対照にする。
ここでの正応答対照は非零応答の検証を意味し、応答の符号は固定しない。
この設計に続く[明示Qの検証](p3_explicit_charge_validation.md)と
[拡張交換模型の実装・小系照合](p3_extended_model_validation.md)、

この対照の残る校正を並行する。直近はN27の追加収束を保留し、本対照の
chirality校正を完了し、次に拡張模型N18Q0の照合へ進む。本書の各段階は
CSL側の条件であり、最近接模型の磁化境界・競合秩序の計算を待たせない。
既知非零応答の再現は、1/9の輸送を物理的なポンプとして解釈する前に必要とする。

## 出版済みの基準と、再現に不足する情報

Gong–Zhu–Sheng, *Scientific Reports* **4**, 6317 (2014) の
[Eq. (1), Fig. 2, Methods](https://www.nature.com/articles/srep06317)を基準とする。
同著者の [arXiv:1312.4519v2](https://arxiv.org/abs/1312.4519v2)
は補足資料を含む著者稿であり、独立した再現研究ではない。

| 項目 | 一次資料で確認できる条件 |
| --- | --- |
| 交換 | `J1=1`、六角形内の第2・第3近接 `J2=J3=J′`。Zeeman 項なし |
| ポンプ例 | `J′=0.5`、`N=3×24×4=288`、U(1) 保持最大 5000 状態 |
| 境界 | x 開放、傾いた格子ベクトル y に沿って周期。`Lx,Ly` は単位胞数 |
| flux | y 境界を横切る全交換の `S+_i S-_j` に `exp(iθ)`、逆項は共役 |
| 応答 | 一方の chirality 枝で右端移送 `+1/2` at `2π`、累積 `+1` at `4π`。別走行で逆符号 |

以上は著者の報告値であり、このリポジトリで得た観測ではない。
`θ=jπ/2` は観測点の記述で、内部の continuation 刻みを指定したものとは読まない。
補足資料では、幅 6 のエントロピーは外挿が必要だったと報告されている。
同資料の SU(2) 保持数を、上表の U(1) bond dimension と取り違えない。
出典: [著者稿の Methods と Supplementary B/E](https://arxiv.org/pdf/1312.4519v2)。

今回確認した本文・補足の記述からは、Fig. 2 走行の整数 QN、全 site/bond 列、
MPS 順序、端の完全な site 列、pinning の具体的係数・配置、sweep/刻み全履歴を
完全には取得できていない。図から全座標と site 番号を復元した監査ではない。
`ΣSz=0` は零磁場・スピン回転対称な CSL を再現するための本計画の選択であり、
原著の Fig. 2 入力ファイルから直接読んだ値ではない。
本計画では偶数 N、`Q=2ΣSz=0`、`Nup=Ndown=N/2` を明示し、
原著との厳密な有限サイズ比較前に端・QN・pinning 条件を追加照合する。
原著図の見た目や `Ly` だけから YC 名・site identity・flux 符号を補わない。

## このリポジトリの座標での模型定義案

以下は原著の bond の種類を現在の座標へ移す**本計画の幾何学的導出**で、
原著の有限 cylinder の site 番号を転記したものではない。
`a1=(1,0), a2=(1/2,√3/2)`、`A=0, B=a1/2, C=a2/2` を用いる。
無限格子上の六角形を巡回順に

```text
A(x,y), B(x,y), C(x+1,y-1), A(x+1,y-1), B(x,y-1), C(x,y-1)
```

と置く。J2 は六角形上で一頂点を飛ばす 6 本、J3 は対向頂点を結ぶ 3 本。
これにより J3 に、同じ距離にある直線鎖上の別種の第3近接を混ぜない。
一単位胞当たりの代表 bond は次の通り。反転した同じ bond は追加しない。

| 種類 | 始点 | 終点 |
| --- | --- | --- |
| J2 | A(x,y) | C(x+1,y-1) |
| J2 | B(x,y) | A(x+1,y-1) |
| J2 | B(x,y) | C(x+1,y) |
| J2 | C(x,y) | A(x+1,y) |
| J2 | A(x,y) | B(x,y-1) |
| J2 | B(x,y) | C(x,y-1) |
| J3 | A(x,y) | A(x+1,y-1) |
| J3 | B(x,y) | B(x,y-1) |
| J3 | C(x,y) | C(x+1,y) |

原点側も含め無限格子の bond を先に定め、両端が保持 site 集合に入るものを残す。
「完全な六角形だけを残す」と端の有効 bond まで消えるため、その生成法は採らない。
y を巻く前の画像差から signed `wy` を付け、wrap は `Ly*a2`。
J2/J3 の横交換にも同じ `(Ja/2)cis(wy*θ)` を使い、`SzSz` は無変化とする。
整数 QN が 2Sz であることを理由に `2θ` を入れない。

この端の切り方では、予想 bond 数は
`N1=(6Lx-2)Ly, N2=(6Lx-4)Ly, N3=(3Lx-2)Ly`。
独立な Python の有理数座標検算で、六角形の辺距離二乗 `1/4`、
J2 の `3/4`、J3 の `1`、画像を含む bond 一意性を確認した。
`(Lx,Ly)=(1,4),(2,3),(3,4),(24,4)` の `(N2,N3)` は
`(8,4),(24,12),(56,28),(560,280)` だった。
これは幾何定義案の照合であり、production builder・MPO・DMRG の検証ではない。

## 実行前のゲートと有限予算での段階

1. J2 を幾何距離、J3 を無限格子の chordless 六角形の対向頂点から独立構築し、
   上のテンプレートと全 bond を照合する。内部 loop、巻き込み loop、向き反転、
   seam gauge の 2π 周期、uniform gauge との同値性を全交換で確認する。
   開放端の外側も含む無限格子で六角形を認定し、最後に端点で切る。
2. 現行 geometry 制約で最小の偶数 N は `(1,4)` の 12 sites、Q=0 の
   Hilbert 次元は `binomial(12,6)=924`。零・一般 flux の独立 ED/MPO と
   DMRG の照合に使うが、軸方向の内部 cut がないので pump は判定しない。
3. `(2,3)` の 18 sites は Q=0 次元 `binomial(18,9)=48620`、内部 cut は一つ。
   sparse ED、残差、状態の縮退を調べ、実空間移送と Schmidt 変化の照合に使う。
   一意な周期的有限系基底状態に半整数 pump を要求しない。
4. 複数 cut のある偶数系は例えば `(3,4)` の 36 sites。
   まず flux なしで bond dimension と独立 seed を変え、chirality、密度、variance、
   実測切断誤差、実時間・メモリを記録する。これは性能・状態準備の予備実験とする。
5. 原著規模への増大は上記の計測から予算を決める。
   小さい系や短い cylinder の零／非量子化応答も保存し、正対照失敗と模型否定を区別する。
   単一 trajectory の theta 点を順次進め、複数 chirality 枝のみ独立出力で並列化する。

全段階で既知の QN 切断異常 guard を維持する。基準状態の縮退・近縮退では
overlap 一つに依存せず、chirality、bulk profile、Schmidt flow、残差を併用する。
予想値 ±1/2 への近さを受理条件や枝選択に使わない。
seed に明示的 chirality 項を加えた場合はモデル変更として別記し、その除去後を検証する。
端の分離、複数 bulk cut、左右打消し、Schmidt 校正、刻み・bond dimension・長さ・幅・
初期状態依存が揃うまで P3 完了としない。4π の bulk sector 帰還と端密度の帰還も分ける。

初回監査で行った計算は上記の幾何学的検算のみだった。その後の拡張模型の
ソース変更・小系ED/DMRGは[実装検証記録](p3_extended_model_validation.md)に分ける。
CSLポンプの再現、相同定、新規性は依然として主張していない。
