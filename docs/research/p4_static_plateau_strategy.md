# P4a: 最近接1/9 plateauの研究方針

更新日: 2026-09-19。状態: **文献と実装を照合した研究計画。新しい数値結果はない**。
実行順の正本は[ロードマップ](../../ROADMAP.md)、物理規約は
[flux設計](../flux_insertion_design.md)とする。

## 今回の判断

最優先を **最近接・等方模型の静的な磁化境界と競合秩序** に置く。
明示Q、bond energy、独立ED、切断校正が利用できるため、この問いに着手できる。
既知CSLの校正は並行する。CSLの非零応答再現は1/9ポンプの物理解釈の条件だが、
最近接模型の静的研究や、短区間の数値的な追跡検証の前提にはしない。

| 検討した進め方 | 得られること・負担 | 採用判断 |
| --- | --- | --- |
| 既知のNN領域で静的比較を進め、CSL校正を並行 | 本来の1/9の問いに早く戻れ、輸送の独立校正も維持できる | 採用。計算資源は静的NNを優先 |
| CSLポンプの再現を全研究に先行 | 輸送測定を先に固められるが、枝準備・長さ依存が静的NN研究も遅らせる | CSL側の手順として残す |
| XXZ・breathing・J2/J3を広く走査 | 安定領域の比較ができるが、模型数と収束調査が増える | NNの基準と費用が得られた後に選ぶ |

直近の問いは「この円筒でQ=N/9が安定になる磁場区間はどこか、その状態にどんな
空間構造があるか」。有限系の区間、bulk plateau、中性ギャップ、Hall応答、
内在的トポロジカル秩序は段階を分けて判定する。

## 既知の領域と競合する説明

基準Hamiltonianは `H0=J Σ_NN Si·Sj`、`H(h)=H0−hΣSz`、`J=1`。
`h` はエネルギー単位のZeeman係数で、磁束角 `θ` とは別の変数である。
初回の静的比較は `θ=0`、`Jxy=Jz=1,J2=J3=0` に固定する。

| 一次資料 | 出版状況・報告 | 方針への反映 |
| --- | --- | --- |
| [Nishimoto–Shibata–Hotta, Nature Communications 4, 2287 (2013)](https://www.nature.com/articles/ncomms3287) | DMRGで1/9 plateauとZ3スピン液体の可能性を報告 | 既知の数値的出発点。相同定の確定結果とは扱わない |
| [Fang et al., PRB 107, L220401 (2023)](https://arxiv.org/pdf/2306.09563) | Eq.(1), Fig.1: iPEPS/9-PESSで `0.35<h/J<0.42`。9-siteのhourglass VBCとgaplessな性質を提案 | `h/J=0.38` を比較用の代表点にし、√3×√3の秩序を許す |
| [He–Yu–Li, PRL 133, 096501 (2024)](https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.133.096501) | VMCでchiral Z3スピン液体を提案 | 複素枝も保持。論文のラベルからK,tや物理Sz応答を自動同定しない |
| [Cheng–Li, PRB 113, 085136 (2026)](https://journals.aps.org/prb/abstract/10.1103/5tvd-253q) | 2026-02-20出版。3×3 windmill VBCの変分エネルギーが既提案より低いと報告 | 27-siteの秩序単位胞も比較対象。著者稿2507.20308は2025年だが、現在は出版済み |
| [Đurić–Sengupta, arXiv:2512.11670v1 (2025)](https://arxiv.org/abs/2512.11670v1) | 著者稿でgaplessなchiral spin density waveを提案。今回、査読誌出版は未確認 | 磁気秩序・gapless候補を残す。数値の規約を未監査のため基準エネルギーには使わない |

`0.35–0.42` は特定手法の報告値であり、厳密境界や本円筒の合格区間ではない。
幅や端が異なる計算でずれても、その事実を保存して原因を調べる。
Fang et al.のFig.3にはbreathing模型の `h/J∇=0.38`、およそ
`0.59<J△/J∇≤1` の1/9領域もあるが、初回の追加パラメータにはしない。
`J2=J3=0.5,Q=0` は[別のCSL測定対照](p3_csl_control_design.md)である。

## 固定Qから磁場区間を求める

`Q=2ΣSz`、`Q0=N/9` とし、各Qで **全交換エネルギー** `E0(Q)` を求める。
一様磁場は固定Q内で `−hQ/2` の定数なので、同じQのh走査でDMRGを繰り返さない。
保存した `E0(Q)` から `FQ(h)=E0(Q)−hQ/2` を再構成する。
境界計算にenergy/siteをそのまま代入しない。

最初の隣接比較は

```text
h− = E0(Q0) − E0(Q0−2)
h+ = E0(Q0+2) − E0(Q0)
Δh = E0(Q0+2) + E0(Q0−2) − 2E0(Q0)
```

である。候補Qの集合を広げたときは、比較した全sectorの下側包絡を使う。

```text
h_lower = max_{Q<Q0} 2[E0(Q0)−E0(Q)]/(Q0−Q)
h_upper = min_{Q>Q0} 2[E0(Q)−E0(Q0)]/(Q−Q0)
```

`h_lower>=h_upper` なら、そのエネルギー集合では有限幅の安定区間がない。
Q0±2だけでは離れたsectorへの飛び越しを除外できず、追加候補としてQ0±4を調べる。
比較したQの範囲を必ず保存し、未探索sectorに対する安定性は未判定とする。
θ=0の等方模型ではspin反転により `E0(Q)=E0(−Q)`。正のhで既知の正Qの鏡像を
重複して解く必要はない。Qを変える際は別の初期MPSを作り、再開中のQは変更しない。

χ・sweep・初期状態を変えた **全エネルギー差の変動** を境界の不確かさへ伝える。
DMRGの変分上界同士の差は厳密な境界の上界・下界ではない。
小さいenergy/site誤差、設定cutoff、正のΔhだけでbulk plateauを宣言しない。
各sectorのSz profileの差を列別に取り、追加磁化が端に局在するかを確認する。
端の磁化励起で区間が狭くなる場合も、直ちにbulk plateauを否定しない。

## 段階と次の限定研究単位

各段階は独立した研究記録を残す。後の段階全体を一つの完了条件にまとめない。
以下のdriverと解析表は**計画**で、専用のplateau driverと単一solveを停止する
外側の時間監視はまだ実装していない。既存研究driverの点間チェックとは区別する。

| 段階 | 最小の問い・ケース | 成果物と進む条件 |
| --- | --- | --- |
| A: N18の静的sector比較 | `(Lx,Ly)=(2,3),θ=0,Q=0,2,4`。各sectorでEDとDMRGを一回ずつ。必要時だけQ=6のEDを追加 | E0、残差、h境界、列別磁化差。有限クラスターの結果として完了できる |
| B: N27の資源・候補準備 | `(3,3),Q0=3,θ=0` の代表1走行から開始 | 時間・メモリ・切断誤差・variance・Sz/bond profile。その後に追加するχまたはseedを選ぶ |
| C: N27の静的比較 | Bの設定でQ=1,3,5。競合する場合にQ=7や別初期状態を追加 | 探索したQ内の境界と候補状態の精度依存。全組合せ走査は行わない |
| D: 長さ・秩序の比較 | B/Cの実測後に `(6,3),N=54,Q0=6` を候補とする | 同じwrap・端で中央の変調と端侵入を比較。次の幅と予算を決める |

AでN18Q2の以前のED結果を利用する場合は、記録されたHamiltonianと参照設定を照合し、
過去のsourceでの証拠と表示する。旧checkpointを新sourceで無理に再開しない。
N9の差分は既存の[明示Q検証](p3_explicit_charge_validation.md)に残し、再走行しない。
AのQ=0,2,4のED基底数はそれぞれ48,620、43,758、31,824。
既存の独立参照はN≤18に限定されており、N27へEDを拡大しない。
N18は二列だけで内部bulk列がない。列別磁化差は記録するが、端局在とbulk応答の
分離はより長い系で行う。

Aではχ=512、6 sweeps、seed=11、cutoff=noise=0の単一設定を用い、小系照合基準
`|E_DMRG−E_ED|/N<1e−8 J`、独立残差ノルム `<2e−6 J`、
基底空間からの漏れノルム `<2e−6`、同じ射影状態との局所Sz差 `<1e−6` を確認する。
ED自身の絶対残差許容値は既存参照の `1e−11 J` に固定し、solverの報告だけでなく
全行列で計算した残差と直交性を確認する。Krylov設定も実行前に固定する。
このχはN18の二分割Hilbert空間の上限であり、より大きい系の収束設定ではない。
EDの有限個のRitz対だけで縮退空間の完全性を保証せず、境界準位を確認する。
DMRGが精度未達のsectorに限り、予算内で6 sweepsを最大一回追加する。
それでも精度不足、またはED未収束なら当該sectorを未解決とし、欠けた境界を補間しない。

初回Aの計算予算は **wall time 10分、Julia/BLAS各1 thread、数値process一つ** とする。
実行時にsweep数・Krylov設定・時間上限を明示して固定し、点間の残時間確認に加え
単一solve中も外側から経過時間を監視する。上限で打ち切った点は未完了として保存する。
既存の[N18 χ比較](p1_qn_truncation_calibration.md)ではχ512・6 sweepsのQ2 DMRGが
中央分解の監査を含めて約24–27秒/点だったが、Q0や初回compile、他の診断・保存の時間は同一ではない。
Bはまずχ256の資源pilotとして別の10分上限を置き、精度を見てχ512の必要性を判断する。
これらは完走時間の保証ではない。C以降の上限とケースは代表点の実測を見て別途決める。
CSL側の数値走行を同時起動してこの割当を超えない。

## 円筒と競合秩序を公平に扱う

現在のwrapは `Ly*a2`。√3×√3の一つの向きを
`A1=a1+a2,A2=−a1+2a2` と取ると、`3a2=A1+A2` なので `Ly%3=0` で整合する。
3×3の周期 `3a1,3a2` も同じ幅条件を満たす。これは本座標での幾何学的導出であり、
文献のYC名の同定ではない。LxはOBCなので3の倍数が必須ではないが、
`Lx=3→6` は同じ端を保つ長さ比較として選ぶ。
N27は3×3の一周期分、N54も狭幅の予備系であり、十分なbulkを仮定しない。
幅4のCSL対照の結果からこれらのVBCを排除しない。幅6等は資源測定後の候補とする。

初期比較は既存の複素ランダムMPSを用い、次に秩序を意識した初期状態を選択的に追加する。
9-site/27-site VBC用の明示的な初期状態構築は未実装であり、単なるseed変更を
それぞれの秩序を準備した証拠としない。微小pinningを加える場合は別模型として記録し、
係数をゼロへ戻した状態同士を比較する。

保存する主要量はE0、Sz profile、bond energy、縦・横スピン相関、Schmidt量、
varianceと実測切断誤差。θ=0のscalar chiralityは三spin独立校正後に追加する。
固定Qでは `⟨Sx⟩=⟨Sy⟩=0` が自動的に成り立つため、これを磁気秩序なしの根拠にしない。
`⟨S+i S−j⟩` も調べる。bond-energy変調は端のpinningでも生じるので中央領域と長さ依存を使う。
全相関行列を用いる現在のbond-energy実装はO(N²)保存量を要し、Bで診断の費用も測る。

候補間エネルギー差がχ/seedによる変動以下、端の変調が中央まで届く、または相関の
減衰を系の長さで分離できない場合は、候補の優劣やbulk相を未判定とする。
中性励起の探索は後続の別単位とし、低励起の端／bulk局在を区別する。
無秩序に見える密度や非零chiralityだけでCSLとしない。

## 輸送へ進む条件と作業範囲

NNの短区間continuationは追跡・精度の診断として進めてよい。
量子化ポンプを解釈する前には、P2の複数cut検証、P3の既知非零応答と零応答対照、
対象状態の静的安定性とbulk/端の評価を揃える。NNの全cycleはその段階で予算化する。
gapless性や枝飛びが解消しない場合は、移送を観測値として残し、量子化Hall係数へ同一視しない。
`2/3`、`0`、その他、未収束を同じ採否基準で保存し、どの値も目標に状態を選ばない。

chiralityの校正と拡張模型N18Q0の照合はCSL側で継続する。GPU/MPI、独自backend、
追加模型の相図、modular量は当面の必須作業にしない。性能は同じ物理精度で測ってから改善する。
研究走行は通常テストへ追加しない。重点約60秒・全体目標約3分・5分超で費用調査という
[AGENTS.md](../../AGENTS.md#practical-test-time-budget)の方針を維持する。
今回の更新は文書だけなので、リンク・整合性・差分を確認し、Julia計算は再実行しない。
