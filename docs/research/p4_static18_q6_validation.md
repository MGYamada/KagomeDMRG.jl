# P4a補足: N18のQ6追加と1/9磁化境界

日付: 2026-09-19。状態: **Q6のED/DMRG照合を完了。Q2の比較内の磁場区間は不変**。
最近接・等方kagome Heisenberg模型で、保存済みのN18・Q=0,2,4へQ=6を1点追加する。
対象の1/9 sectorはQ2であり、Q6はその磁場区間を制限し得る比較対象である。
[以前の隣接sector比較](p4_static18_validation.md)は当時の証拠として保持する。

## 問いと固定条件

全交換エネルギーを`E_Q`、磁場込みを`F_Q(h)=E_Q-hQ/2`とすると、
比較集合`{0,2,4,6}`でQ2が最低になる開区間は

```text
h_lower = E2-E0
h_upper = min(E4-E2, (E6-E2)/2)
```

である。Q2からQ6への変化は物理的`ΔSz=2`なので、後者には1/2が必要となる。
旧上限は`0.4869821958059415 J`で、`E6/J < 2E4/J-E2/J = -6.468375352858541`
なら新しい上限候補が小さくなる。候補が下限以下なら有限幅の区間はなくなる。
これらは比較したsector内の包絡であり、未探索Qやbulkに対する安定性は含めない。
固定Qでhを変えても定数のenergy shiftなので、hグリッドのDMRGは行わない。

| 項目 | 実行前に固定した条件 |
| --- | --- |
| 模型 | Jxy=Jz=1、最近接のみ、hz=θ=0、chirality seedなし |
| 幾何 | `(Lx,Ly)=(2,3),N=18`、軸OBC、wrap `3a2`、完全単位胞の端、順序x/y/A,B,C |
| 新規sector | Q6、物理Sz=3、Nup=12、Ndown=6、ED次元18,564 |
| DMRG | 新規複素MPS、seed11、初期linkdim4、χ上限512、6 sweeps、cutoff=noise=0 |
| 局所Krylov | tol=`1e-11`、krylovdim40、maxiter20 |
| 独立ED | BlockLanczos、nev=blocksize=4、seed5678、krylovdim80、maxiter200、tol=`1e-11` |
| 追加計算 | 基準未達時のみ、同じQ6状態から追加6 sweepsを最大1回 |
| 資源上限 | 起動・compile・診断・保存込み300秒、数値process一つ、Julia/BLAS各1 thread |

以前の段階Aと同じ基準を使う。energy/site差≤`1e-8 J`、独立残差とground cluster外norm≤
`2e-6`、射影して対応付けた同じED状態とのSz差≤`1e-6`。
電荷・normの誤差≤`1e-12`、MPO/ED期待energy差・bond和・Schmidt/密度差≤`1e-10`。
EDの全行列残差≤`1e-11 J`と直交性、ground clusterより上の要求準位を確認する。
有限個のRitz対では全低エネルギー空間の完全性を保証しない。
raw varianceと独立残差の二乗の差を保存するが、丸め床以下のvarianceを精度保証に使わない。

## 数値結果

初回6 sweepsで全9個の精度基準とcheckpoint読込みを通過し、追加sweepは不要だった。
全数値・profile・設定・hashは[数値記録](data/p4_static18_q6_validation.toml)、
外側の時間・CPU・メモリは[実行記録](data/p4_static18_q6_execution.toml)を正本とする。
ローカルのEDベクトルとtrialは`outputs/p4-static18-q6-20260919/`に保存した。

| Q6の量 | 実測値 |
| --- | ---: |
| 独立EDのE6/J | −6.236777141214652 |
| DMRGのE6/J | −6.236777141214646 |
| energy/site差 | 3.46e−16 J |

Q6の中央cutで可能な固定Q Schmidt rankの上限は176であり、今回の最終次元と一致する。
これは切断なしの小系照合であり、大系のχ512で十分という意味ではない。
求めた4個のED準位内ではground clusterは1次元だった。次準位との間隔は
約`0.1109636154 J`であり、このQ6有限系の準位間隔に限る。

| Q2の磁場境界/J | Q0,2,4のみ（以前のED） | Q6追加後（ED） |
| --- | ---: | ---: |
| 下限h− | 0.258520158166557 | 0.258520158166557 |
| 上限h+ | 0.486982195805942 | 0.486982195805942 |
| 幅Δh | 0.228462037639384 | 0.228462037639384 |

Q6からの上限候補は`h26/J=0.6027813016278856`で、旧上限より`0.1157991058219441 J`高い。
旧上限で`F6-F2=0.2315982116438882 J>0`であり、Q6はこの区間へ割り込まない。
下限を決めるのはQ0、上限を決めるのは引き続きQ4である。
**比較したQ=0,2,4,6の範囲では**`0.2585201582<h/J<0.4869821958`を維持する。
端点では境界を決めるsectorと縮退する。

| 列磁化の差 | 第1列ΔSz | 第2列ΔSz | 合計 |
| --- | ---: | ---: | ---: |
| Q2→Q6 | 0.8314423558 | 1.1685576442 | 2 |
| Q4→Q6 | 0.6975913424 | 0.3024086576 | 1 |

Q6自身の列Szは`(1.4014930675,1.5985069325)`。
これは選択された有限系状態間の密度差であり、軸方向の輸送や端局在の証拠ではない。
raw varianceは`+9.95e−14 J²`、差し引きの丸めscaleは`8.64e−13 J²`。
独立残差二乗が約`4.18e−24 J²`なので、raw varianceの値は丸めに支配されている。

## 判定の範囲

Q≥8は未探索として残す。θ=0の零磁場交換模型はspin反転対称なので、
正のhで負Qの鏡像を重複して最適化しない。
二列しかないため、密度差を端局在とbulk磁化に分離できない。
特に旧Q4は観測したground clusterが2次元で、そのprofileは選ばれた状態に依存する。
磁化区間、neutral bulk gap、秩序、Hall応答、相同定を同じ結論として扱わない。

Q6が上限を変えない場合、Q8以降を自動的に追加せず、保存済みNN N18Q2の
近接中性準位の密度・bond応答を次の独立候補とする。
既存のQ2基底と最初の励起doubletの間隔は約`0.0018646750 J`で、
その空間構造は未測定である。保存ベクトルの残差・由来を再確認し、doublet全体へ
射影した遷移強度を使えば、縮退基底の任意の取り方による模様の違いを避けられる。
新規DMRG/対角化なし、120秒上限の別単位として予算化し、bulkのVBC同定とはしない。
N27追加収束の保留、N36 CSL状態準備・非零ポンプの未実施は維持する。
