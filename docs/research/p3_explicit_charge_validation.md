# 明示的な整数電荷 Q の小系検証

2026-09-19。最近接 Heisenberg 模型の固定電荷を指定し、零磁化対照と
隣接磁化 sector の計算を可能にする検証単位。既知 CSL の拡張結合・
chirality 診断と研究サイズのポンプ検証は、この単位には含めない。

## API と保存契約

`target_sector(N; Q=...)`、`initial_mps(...; Q=...)`、`run_dmrg(...; Q=...)`
は整数 `Q=2Sz_total` を指定できる。`−N≤Q≤N` と N との偶奇一致を検証する。
`Nup=(N+Q)/2` は整数の加算が overflow しない形で計算する。
省略時は従来の 1/9 sector を選び、`N % 9 == 0` を要求する。
`psi0` が別の電荷でも省略時の意味は変わらず、不一致を拒否する。

`load_checkpoint`、`resume_dmrg`、`continue_flux` は保存状態・始点の
検証済み Q を継承する。明示した Q は期待値として一致を要求し、途中で変更しない。
schema 1 の既存 model/state 電荷欄を利用し、baseline、MPS、密度の和とも照合する。
旧ソースの snapshot は source identity が異なるため拒否する。自動移行は実装しない。

独立 ED は production の sector helper を呼ばず、bit-spin 基底から電荷を検証する。
18 サイトまで、dense 行列は次元 4,096 まで、疎固有値 helper は次元 48,620 までとする。
`N=18,Q=0` の基底数・上限契約は確認対象だが、その固有値計算は今回実施しない。
完全偏極 sector の一次元 Hamiltonian は構築できるが、複数 Ritz 対を求める
疎固有値 helper は一次元を受け付けない。

## 実行前に固定した範囲

研究 driver は [validate_charge_sectors.jl](../../examples/validate_charge_sectors.jl)。
通常の回帰 suite に研究点を追加せず、次の5点だけを計算する。

| 幾何 | Q | θ | 独立 ED 次元 |
| --- | ---: | ---: | ---: |
| `(1,4)`, N=12 | 0 | 0、0.37 | 924 |
| `(1,3)`, N=9 | −1、1 | 0 | 各126 |
| `(1,3)`, N=9 | 3 | 0 | 84 |

全点で最近接 `Jxy=Jz=1`、外場なし、seam gauge を用いる。
Julia/BLAS 各1 thread、seed 11、最大 bond 次元64、8 sweep、cutoff/noise=0、
局所 eigensolve tolerance `1e-12`、Krylov 次元30、最大反復10とする。
N12 の θ=0.37 は同じ site indices の零 flux 状態から逐次開始する。
他の sector は独立に初期化する。点の間に300秒の経過時間上限を確認し、超過時は
後続点を開始しない。起動・import の時間と、driver 内の時間を区別する。

ED は全固有対を求め、`1e-10` 以内の最低準位を全て射影に含める。
DMRG の独立残差、基底空間への射影残差、同じ射影状態との密度差を比較する。
12 サイトの最大 Schmidt rank は64なので、この設定は有限 χ の収束走査ではない。
seam/uniform の ED 行列を局所 Sz 回転で照合し、独立 seed 33 の複素 MPS に対する
MPO 作用を両ゲージで比較する。巨大な全 Hilbert 空間 MPO 行列は作らない。

事前基準は energy/site 誤差 `<1e-8`、全系残差・基底空間からの漏れ `<2e-6`、
局所 Sz 誤差 `<1e-6`、電荷・norm 誤差 `<1e-12`、ゲージ行列と MPO 作用誤差 `<1e-11`。
trial snapshot を保存し、省略 Q での load が同じ電荷・状態を戻すことも確認する。
これらの点は診断付き continuation の受理点として扱わない。

## 解釈の範囲

N9 では `E0(-1)=E0(1)` と、隣接 sector 差
`h−=E0(1)−E0(-1)`、`h+=E0(3)−E0(1)` を記録する。
磁場項は `−hQ/2` なので、隣接磁化は `ΔQ=2` に対応する。
これは有限クラスターのエネルギー差であり、plateau の証明ではない。
両幾何とも Lx=1 で軸方向 cut がないため、ポンプ・量子化・相同定は評価しない。
N18Q0 の相互作用系、拡張結合、chirality と既知 CSL 対照は未検証である。

## 実測結果

5点とも上記の全基準を通過した。数値・設定・依存版・source hash の正本は
[実行記録 TOML](data/p3_explicit_charge_validation.toml)。trial snapshot は
`outputs/p3-charge-sectors-20260919/trial/` に保存した。

| 12 | 0 | 0.37 | −4.879310860299527 | 9.39e−13 | 5.29e−13 |

最大 energy/site 誤差は `1.26e−15`、局所 Sz 誤差は `1.17e−14` 未満。
N12 の θ=0.37 のゲージ行列差は `3.22e−15`、全点・両ゲージの
MPO 作用誤差は `8.58e−16` 以下だった。全snapshotで省略 Q による復元が一致した。
N12 の最低準位は各点で非縮退、N9・Q=±1 の零 flux は各2重縮退であり、
後者では全基底空間への射影を用いて状態依存の密度を比較した。

N9 の ED から `h−=8.88e−16`（丸めの範囲で0）、`h+=0.48649496096498446` を得た。
`E0(-1)` と `E0(1)` の差も `8.88e−16` であり、spin 反転と整合する。
遠い Q を含めた下側包絡、端の磁化、長さ・幅への依存は調べていない。

研究driver全体は83.50秒、import後に測る内部時間は81.18秒だった。
最初のDMRGはJITを含め40.41秒、残り4点は各0.28–1.78秒。
密EDはN12で各約0.46–0.48秒、N9で各0.002–0.004秒だった。
内部時間には追加の診断・保存とその初回compileも含む。

統合 `Pkg.test()` は1回で **1,263 / 1,263件成功**、Test計測4分17.3秒、
起動・precompile込み270.14秒だった。重い計算の追加を避け、既存のDMRG・
固有値例を非既定Qへ置換した。新たな検査は電荷境界・不整合・解析状態の保存に絞った。
独立担当によるQ規約・保存・ED・研究driverの読み取り監査でも数値上の指摘はなかった。
3分のsuite目標は未達であり、通常作業は対象分野の重点確認を使う。

計算後、driverの割込み・例外時に状態を `interrupted` / `failed` と記録する処理を補正した。
実測TOMLのdriver hashは計算時の値のまま保持し、数値計算やproductionには変更を加えていない。
この記録処理の補正後に数値走行は繰り返していない。

今回完了したのは **明示QのAPIと最近接小系照合** である。
次はJ2/J3の独立幾何、chiralityの三spin校正と保存契約を整え、
拡張模型のN12Q0、および軸cutのあるN18Q0で残差・射影・移送を検証する。
この次段階の完了まで、ロードマップP3a全体は完了としない。
