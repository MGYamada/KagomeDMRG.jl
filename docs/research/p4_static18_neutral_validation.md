# P4a補足: N18Q2の近接中性二重項の遷移強度

日付: 2026-09-19。状態: **保存済みED部分空間の再検証と、密度・NN bondの遷移測定を完了**。

最近接Heisenberg模型のN18・Q2基底から約`0.00186467503 J`上の二重項は、
局所SzとNN交換演算子の両方に非零の遷移強度を持つ。
今回の保存ベクトルで、基底の円周運動量`k=0`、二重項の`k=±2π/3`を再確認した。
各局所演算子のconnected varianceを足した量に占める二重項の割合は、
Szで約4.01%、bondで約8.40%だった。
これらは二列の有限円筒の行列要素であり、bulk gap、VBC、磁気秩序、相同定の結果ではない。

## 問いと計算範囲

[Q6追加比較](p4_static18_q6_validation.md)では、比較したQ=0,2,4,6内の
Q2の磁場区間が変わらなかった。次に、保存済みQ2の近接中性準位が
どの密度・結合変調に応答するかを調べた。ここで中性は`ΔQ=ΔM=0`を意味する。

| 項目 | 今回の範囲 |
| --- | --- |
| 模型 | 最近接等方Heisenberg、J1=1、J2=J3=h=θ=0 |
| 幾何 | `(Lx,Ly)=(2,3)`、N18、軸OBC、円周PBC、wrap=`3a2=(1.5,3√3/2)` |
| 端と順序 | complete cells、軸外へ出るbondを除く。`x→y→A,B,C` |
| 電荷 | Q=2Sz=2、M=1、Nup=10、Ndown=8、M/Msat=1/9 |
| 保存状態 | 独立spin-basis EDの4列、次元43,758。測定対象は基底と最初の二重項 |
| 演算子 | 18個の物理Sz、30本のNN bondの`B_b=Si·Sj` |

四つの取得準位は完全な低エネルギースペクトルの数学的保証ではない。
最低準位一つ、続く二重項、次の取得準位が`1e-8 J`のcluster閾値で分かれることを確認し、
保存された二列をともに使った。観測された二重項内での任意の基底選択を物理的な模様にしない。

## 測定の定義と独立検証

正規化基底を`g`、正規直交した励起二列を`E=(e₁,e₂)`とし、

```text
A[i,α] = <eα|O_i|g>
P_ex   = E E†
C[i,j] = Σα conj(A[i,α]) A[j,α] = <g|O_i P_ex O_j|g>
w_i    = C[i,i]
```

と定義する。`E→EU`に対し`A→A conj(U)`であり、Cとwは不変である。
Cは**この二重項へ射影した**行列で、全励起を含むconnected correlationではない。
生の複素振幅とCの実部・虚部を保存したが、個々の振幅には状態の位相・縮退基底の任意性がある。

新しい[独立遷移helper](../../examples/static18_transition_reference.jl)はbit=1をUpとし、
Szの対角作用と、反平行spin対を係数1/2で交換する作用を直接計算する。
productionの格子・MPO・観測量は呼ばない。別構成のCartesian Pauli/Kronecker演算子による
3-spin校正で、非零の虚部、複素unitary混合、基底の並べ替え、入力保持、複素倍率を照合した。
最大dense演算子は8×8で、S²とS⁺も同じ独立Pauli参照に照合した。

[解析driver](../../examples/analyze_static18_neutral.jl)は次を実測する。

- 入力hash、charge、完全な固定Q基底、幾何・bond、規格化・直交性。
- 独立距離参照から再構成した疎Hamiltonianによる、保存4ベクトルの全空間残差。
- active translation `T:(x,y,s)→(x,(y+1) mod 3,s)`、`T³=I`、Hamiltonianとの可換性、部分空間の閉包。
- 実データの励起二列の複素unitary混合、基底状態の全体位相変更に対するCの不変性。
- `Σ_i A_Sz[i,α]≈0`、`Σ_b A_B[b,α]≈0`。固定Mと交換Hamiltonianの和則であり、重みの和は零にしない。
- 局所分散への重みの上限、円周Fourier変換のParseval則、source/inputの走行前後の不変性。

局所分散は基底の期待値から、
`v_i=1/4−<Sz_i>²`、`v_b=3/16−<B_b>/2−<B_b>²`を計算する。
後者はspin 1/2の`B_b²=3/16−B_b/2`による。
`0≤w≤v`を確認し、下表の割合は`Σw/Σv`と定義する。
これは全系の演算子`ΣO`の分散、static susceptibility、または秩序の割合ではない。

円周の演算子orbitごとに
`O_k=Σ_{y=0}² exp(−iky) O_{T^y i}/√3`を用いる。
`T|e_k>=exp(ik)|e_k>`の規約で、選択されるkは励起と基底の運動量差である。
位置重みwはorbit内で一様でも、周期3の位相はCとFourier応答に残る。

## 残る問題と次の判断

近接中性二重項の局所演算子への結合を有限系の数値証拠として保存した。
磁化区間、bulk plateau、中性bulk gap、長距離秩序、Hall応答は別の問いとして残る。
N27の累積4-sweep trialは未収束のまま保持し、追加収束の保留を維持する。

N18の同じデータの再加工だけを続けず、次の候補は既存ロードマップの
**拡張模型N36・Q0・零fluxの状態準備と資源pilot**とする。
これはJ2=J3=0.5のCSL対照側の別単位で、NN・1/9の状態や非零ポンプとは区別する。
開始前にχ・sweep数・seed・診断範囲と外側時間上限を限定し、trial保存と資源量をまず測る。
今回そのN36計算は実施していない。NN側のbulk評価には、端・長さ・幅・競合初期状態の
比較が必要であり、小系結果によって完了とはしない。
